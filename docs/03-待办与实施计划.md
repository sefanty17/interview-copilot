## 七、执行规范（速查，细则见对应文档）

### 分工硬边界

- 主线（贵模型）只做三件事：**框架探测 → 写规格 → 验收**。不直接改代码。
- 所有执行派 `deepseek-v4.1-flash` 子 agent。规格写到「填空题」粒度：文件 / 行号 / 原样 / 禁区 / 验收标准。
- **验收不信子 agent 报告**：自己跑 `mvn test`、`vue-tsc`、`curl` 实测、`getComputedStyle` 量数值。

### 子 agent 三条禁令

1. 不许跑 git 命令（提交归主线）
2. 不许用裸 `mvn`（只能用 `scripts/mvn.sh`）
3. 不许动 `.workbuddy/memory` 之外的历史文档

### 跨端契约（改错就断链）

- **SSE 事件名**：出自 `script_engine/responses.rs:13` + `message_system/responses.rs:32`，`frontend/src/api/chat.ts` 与 `InterviewRoomView.vue` 按名消费。缺 `status:reset` 前端永久等待。
- **事件 type 串**：用 Rust 注册键（`choices` / `dialogue`），不是类名（`choice` / `dialog`），写错落 `NoopEvent`。
- **payload 字段**：camelCase，与 Rust `serde(rename_all)` 一致。
- 这三类改动由主线亲自复核，不外包。

### 前端复刻规程

- 允许改：文案、数据字段业务含义、无对应页面的新增板块（用现有零件拼装）
- 不允许改：布局结构、栅格比例、组件形态、字号/圆角/间距/颜色/动效参数
- 目录路径与文件名照搬原版（`components/settings/pages/SettingsText.vue`），只增不改名
- 审查标准：`docs/01-前端复刻作业规程.md`；组件进度：`docs/02-复刻台账.md`；逐页数值：`docs/design/01~20`

### 环境坑

- `pip` 直连与清华源均 502 → 用标准库写解析器

- Bash 里 `python -c "…\`反引号\`…"` 会被 shell 替换破坏 → 改文档用 Edit 工具
- `java -jar` 运行中锁 target jar → 先停进程再 `mvn package`
- `taskkill //F //PID` 在 Git Bash 不转换 → 用 PowerShell 工具
